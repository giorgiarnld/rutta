# Home Sensor Dashboard

Home Sensor Dashboard is a Kotlin application that simulates a smart home monitoring system.

## Features

- Temperature monitoring
- Motion detection
- Smoke detection
- Water leak monitoring
- Battery level tracking
- Alert generation
- Console dashboard
- Sensor statistics

## Project Structure

```
src/
 ├── config
 ├── models
 ├── services
 ├── utils
 └── resources
```

## Run

```bash
./gradlew run
```
